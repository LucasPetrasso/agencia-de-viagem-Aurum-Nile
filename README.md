# Aurum Nile

O **Aurum Nile** é um projeto de **site turístico inspirado no Egito**, desenvolvido com o objetivo de praticar e aprimorar conhecimentos em **HTML e CSS**, criando uma experiência visual inspirada na cultura, história e paisagens egípcias.

O projeto foi desenvolvido buscando combinar **design, organização e responsividade**, criando uma interface agradável tanto para computadores quanto para dispositivos móveis.

## Objetivo do Projeto

O principal objetivo do Aurum Nile foi colocar em prática conceitos fundamentais de desenvolvimento **Front-End**, trabalhando desde a estruturação das páginas até a criação de uma identidade visual própria para o projeto.

Durante o desenvolvimento, foram praticados conceitos como:

* Estruturação semântica com **HTML5**;
* Organização e estilização com **CSS3**;
* **Flexbox** para criação de layouts;
* Design responsivo;
* Menu de navegação e versão mobile;
* Criação de **Hero Sections**;
* Utilização de imagens como elementos visuais;
* Gradientes e efeitos visuais;
* Efeitos de `hover`;
* `text-shadow` e estilização de textos;
* Organização de elementos utilizando diferentes propriedades de posicionamento;
* Criação de layouts adaptáveis para diferentes tamanhos de tela;
* Definição de breakpoints para responsividade.

## Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, utilizando **media queries** e breakpoints para adaptar a estrutura e os elementos da interface.

A proposta foi garantir uma experiência consistente tanto em **desktops quanto em tablets e smartphones**.

## Tecnologias Utilizadas

* **HTML5**
* **CSS3**

## O que foi praticado

Mais do que construir uma página visualmente agradável, o Aurum Nile serviu como um exercício para consolidar conhecimentos de **HTML e CSS**, principalmente na criação de layouts, organização de conteúdo, estilização e desenvolvimento responsivo.

O projeto também ajudou a desenvolver uma visão mais prática sobre como transformar uma ideia visual em uma interface funcional utilizando apenas tecnologias fundamentais do Front-End.

## Próximos passos

O projeto pode futuramente receber novas funcionalidades utilizando **JavaScript**, como interações com elementos da página, menu mobile mais dinâmico, formulários e outros recursos que tornem a experiência mais próxima de uma aplicação real.
